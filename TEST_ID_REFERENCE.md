### Best Practices
1. **Prefer test IDs over text selectors** - More stable and language-independent
2. **Use descriptive names** - `data-testid="user-settings-save-button"` is better than `data-testid="button-1"`
3. **Follow naming conventions** - Use kebab-case and include element type (button, select, input, etc.)
4. **Add test IDs to all interactive elements** - Buttons, dropdowns, inputs, links, etc.
5. **Document new test IDs** - Update this reference when adding new test IDs

## 🔄 Naming Conventions

- **Buttons**: `{action}-button` or `{context}-{action}-button`
- **Dropdowns**: `{context}-select` or `{purpose}-select`
- **Inputs**: `{field-name}-input`
- **Links**: `{destination}-link`
- **Containers**: `{purpose}-container`
- **Cards**: `{content-type}-card`
- **Dynamic elements**: `{base-name}-{variable}` (e.g., `section-content-{sectionName}`)
