## Legend

### Type Codes
- `branch`: Branch/PR diff security review
- `audit`: Full codebase security audit
- `staged`: Staged changes security review
- `summary`: Executive summary document
- `constitution`: Security constitution/standards
- `historical`: Archived security documents

### Risk Levels
- `CRITICAL`: Immediate action required
- `HIGH`: High risk, prioritize remediation
- `MODERATE`: Medium risk, plan remediation
- `LOW`: Low risk, address as resources allow
- `INFORMATIONAL`: No direct risk, informational only

### Findings Format
`C:H:M:L` = Critical:High:Medium:Low findings count

### OWASP Categories
Comma-separated list of OWASP Top 10 2021 categories (A01-A10)
